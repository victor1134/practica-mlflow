# data/

`EV_data_by_country_2026.csv`: *EV SALE GLOBALLY 2010 - 2025 | FORECASTING 2035*
(Kaggle, `ahsan442002/ev-sale-globally-2025`, licencia Apache 2.0). 49 375 filas × 9 columnas, ~3.6 MB.

| Columna | Qué es |
| --- | --- |
| `region_country` | país o región agregada |
| `category` | `Historical`, `Projection-STEPS`, `Projection-CPS` |
| `parameter` | indicador: `EV sales`, `EV stock`, cargadores, precios... |
| `mode` | `Cars`, `Buses`, `Trucks`, `Vans`, `2 and 3 wheelers`... |
| `powertrain` | `BEV`, `PHEV`, `FCEV`, `EV` (= BEV + PHEV)... |
| `year` | 2010–2035 |
| `unit` | unidad de `value` |
| `value` | valor del indicador |
| `Aggregate group` | `Other` / `Projection_country` = países; el resto son agregados |

Es pequeño y tiene licencia abierta, por eso sí va en Git.
